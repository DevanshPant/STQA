  1. Missing values: checked every column — {{ m.preprocessing.missing_values }} found, so no imputation was needed (median / mode fill is in place for safety).
  2. Cleaning: trailing spaces removed from maker names → {{ m.preprocessing.makes_after_cleaning }} makers.
  3. Normalisation: Motor (kW) ranges {{ m.preprocessing.motor_raw_range[0] }}–{{ m.preprocessing.motor_raw_range[1] }}. Min-Max maps it to 0–1; Z-score gives mean 0 and standard deviation 1.
  4. Discretization: efficiency split into 4 bins. Equal width gives uneven groups ({% for k, v in m.preprocessing.equal_width.items() %}{{ k }} {{ v }}{% if not loop.last %}, {% endif %}{% endfor %}); equal frequency puts about 300 cars in each.

Exp 4 — Gradient descent and feature scaling

Multiple linear regression (efficiency from model year, motor kW and recharge time) trained with batch gradient descent written from scratch in NumPy, for {{ m.gradient_descent.iterations }} iterations.

  • Scaled features (Z-score), learning rate 0.1: reached the optimum cost {{ m.gradient_descent.optimal_cost }} in {{ m.gradient_descent.scaled_converged_at }} iterations.
  • Raw features, learning rate 1e-8: still at cost {{ m.gradient_descent.raw_final_cost }} after {{ m.gradient_descent.iterations }} iterations — far from the optimum.
  • Raw features, learning rate 1e-6: the cost exploded and diverged within {{ m.gradient_descent.raw_diverged_after }} iterations.

Why: model year is around 2,020 while recharge time is around 10, so the cost surface is a long, narrow valley. One learning rate is either too big for the year direction or too small for the others. Scaling makes every feature comparable, so a single learning rate works for all.

{{ figure("ml_04_gradient_descent.png", "Fig. 4 — Cost per iteration (log scale). Scaled features converge almost immediately; raw features crawl or blow up.") }}

Exp 6 — Gaussian Mixture Model (latent variables)

A GMM assumes the data comes from a few hidden (latent) Gaussian groups and gives each car a probability of belonging to each one, instead of a hard label like K-Means. Trained with the EM algorithm on model year, motor kW, recharge time and efficiency: {{ m.gmm.components }} components, converged in {{ m.gmm.iterations }} iterations.

Silhouette {{ m.gmm.silhouette }}, AIC {{ m.gmm.aic }}, BIC {{ m.gmm.bic }}. On average the model is {{ "%.0f"|format(m.gmm.avg_max_probability * 100) }}% sure about a car's state.

Exp 7 — Linear and non-linear dimensionality reduction

The {{ m.dimred.original_dims }}-feature data was squeezed down to 2 dimensions to see its structure.

  • PCA (linear): {{ m.dimred.components_90 }} components keep 90% of the variance; the first two keep {{ "%.0f"|format(m.dimred.pc1_pc2_variance * 100) }}%.
  • t-SNE (non-linear): keeps nearby cars close together, so similar models form tight islands. Took {{ m.dimred.tsne_seconds }} s.

Colour shows efficiency class. PCA spreads the classes along a broad gradient; t-SNE separates them into clearer local groups but its axes have no direct meaning.
